# PitchLab Legal Site

Static website ready for GitHub Pages.

## Publish
1. Create a new GitHub repository, for example `pitchlab-legal`.
2. Upload `index.html`, `privacy.html`, `terms.html`, and `support.html`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will publish the site at a URL like:
   `https://YOUR-USERNAME.github.io/pitchlab-legal/`

URLs:
- Privacy: `https://YOUR-USERNAME.github.io/pitchlab-legal/privacy.html`
- Terms: `https://YOUR-USERNAME.github.io/pitchlab-legal/terms.html`
- Support: `https://YOUR-USERNAME.github.io/pitchlab-legal/support.html`

IMPORTANT:
The site currently uses `privacy@pitchlab.app` and `support@pitchlab.app`.
If you do not own `pitchlab.app`, replace these with email addresses you actually control before publishing.
